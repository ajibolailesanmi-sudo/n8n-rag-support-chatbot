# Backups and restoring files

## What we back up

- **Microsoft 365 (Business and Premium plans):** email, OneDrive, SharePoint and Teams are backed up every day and each backup is kept for 1 year. On the Essentials plan, Microsoft 365 backup is an add-on at $4 per user per month.
- **Office servers and network storage (every plan, for servers we manage):** backed up every night and kept for 30 days, with a copy stored off-site.

## Recover a deleted file yourself

Files deleted from OneDrive or SharePoint usually stay in the recycle bin for 93 days. Open OneDrive or the SharePoint site in a browser, choose Recycle bin, select the file and choose Restore.

## Ask us to restore something

Submit a restore request in the client portal. Tell us what you need back (a file, folder, mailbox or whole site), where it was, and the date it was last right.

Restores are handled as Priority 3. If the loss stops someone from working, say so in the request and we treat it as Priority 2.
