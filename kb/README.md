# Knowledge base (sample content)

These 15 help articles are sample content written for this Solvant Labs demo build. They describe a fictional managed IT services firm, which is never named. Prices, times and policies are invented for testing and are not an offer from anyone.

In the live demo each article is a Google Doc in one Drive folder. The `40 - Sync Knowledge Base` workflow reads that folder, so editing a doc and running the sync is how the knowledge base is updated. These Markdown files are the source the docs were created from.

Deliberate gaps: the articles say nothing about Mac support, Google Workspace, the office address, nonprofit discounts, free trials, which antivirus product is used, phone systems or website design. The test set asks about these to check that the assistant says "I'm not sure" instead of guessing.
